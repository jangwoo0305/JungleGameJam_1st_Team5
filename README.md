## 🎮 게임 개요

### 컨셉

산타가 적의 감시를 피해 맵 곳곳의 집에 선물을 배달하는 **스텔스 타임어택 게임**입니다. 핵심 메커니즘은 **눈사람 변신**을 통한 전략적 은폐입니다.

### 게임플레이

- **목표**: 제한 시간 내 최대한 많은 집에 선물 배달
- **장르**: Top-view 스텔스, 타임어택
- **난이도**: 적의 시야를 피하고, 변신 횟수를 관리하며, 최적의 경로를 찾아야 함

---

## ✨ 주요 기능

### 1. 🎅 플레이어 시스템 (Santa)

- **8방향 Top-view 이동**: WASD 또는 화살표 키로 자유로운 이동
- **눈사람 변신**: Space 키로 변신하여 적의 시야에서 완전히 은폐
  - 변신 중에는 이동 불가
  - 변신 해제는 Space 재입력 또는 시간 경과
- **자원 관리**: 눈덩이 아이템 획득으로 변신 횟수 충전

### 2. 🕵️ 적 AI 및 감지 시스템

- **순찰 패턴**: 정해진 경로를 왕복하거나 구역을 루프하며 배회
- **시야 시스템 (FOV)**:
  - 원뿔형(Cone) 시야 시각화
  - Raycast 기반 장애물 판정 (벽 뒤는 감지 불가)
- **감지 로직**:
  - 산타 상태: 시야 진입 시 즉시 발각
  - 눈사람 상태: 시야 내에 있어도 무시

### 3. 🎁 배달 시스템

- **목표 지점**: 맵 곳곳에 배치된 빛나는 파티클이 있는 집
- **상호작용**: `F` 키로 배달 완료
- **레벨 디자인**:
  - 안전 구역(Dead Zone): 건물과 장애물로 형성된 은폐 공간
  - 전략적 동선: 적의 순찰 경로 사이에 눈덩이와 집 배치

### 4. 🕒 게임 루프

- **시간 제한**: 타임어택 방식
- **시간 연출**: 시간 경과에 따라 배경이 밤에서 낮으로 변화
- **점수 시스템**: 실시간 배달 성공 횟수 표시
- **승리/패배 조건**:
  - **패배**: 시간 종료 또는 적에게 발각
  - **승리**: 제한 시간 내 최대한 많은 배달
- **결과 화면**: 최종 배달 횟수, 최고 기록, 재시작 버튼

## 🎯 조작법

| ------------------------ | ----------------------- |
| **WASD** / **화살표 키** | 8방향 이동              |

| **F**                    | 선물 배달 (집 근처에서) |

## 🎨 게임 시스템 상세

### 플레이어 시스템 (Santa)

#### 이동 방식

- **8방향 Top-view (상단 시점) 이동**
- 부드러운 이동 애니메이션

#### 핵심 스킬: 눈사람 변신 (Space)

- **기능**:
  - 변신 중 이동 불가
  - **적의 시야에서 완전히 은폐**됨
- **해제**:
  - 다시 Space 입력 시
  - 일정 시간 경과 후 자동 해제

#### 자원 관리

- **변신 횟수**: 화면 UI에 현재 가능한 변신 횟수 표시
- **아이템 충전**: 맵상의 '눈덩이' 아이템 획득 시 변신 횟수 `+1`

---

### 적 AI 및 감지 시스템 (NPC)

#### 행동 패턴 (Patrol)

- 정해진 경로를 왕복하거나 특정 구역을 루프하며 배회

#### 시야 시스템 (Field of View)

- **시각화**: 적 전방에 원뿔형(Cone) 메시/기즈모 표시
- **장애물 판정**: **Raycast**를 사용하여 벽 뒤에 숨은 플레이어는 감지 불가

#### 감지 로직

- **산타 상태**: 시야 진입 시 즉시 발각 (게임 오버 또는 시간 페널티)
- **눈사람 상태**: 시야 내에 있어도 일반 오브젝트로 취급하여 무시

---

### 레벨 디자인 및 목표 (Delivery)

#### 목표 지점 (House)

- 맵 곳곳에 배치된 빛나는 파티클이 있는 집
- 상호작용 키(`F`)를 통해 배달 완료
  - [추가] 상호작용 최소 시간 등의 요소로 난이도 조절

#### 레벨 구성

- **안전 구역 (Dead Zone)**: 건물과 장애물을 배치하여 적의 시야가 닿지 않는 은폐 공간 형성
- **동선 설계**: 적의 순찰 경로 사이사이에 눈덩이 아이템과 집을 배치

---

### 게임 루프 및 UI (Game Loop)

| **구분**        | **주요 내용**                                                                   |
| --------------- | ------------------------------------------------------------------------------- |
| **시간 제한**   | 타임어택 방식. 시간이 흐를수록 배경이 밤에서 낮으로 변화 (연출).                |
| **점수 시스템** | 배달 성공 횟수를 실시간으로 카운트하여 상단 UI에 표시.                          |
| **승리/패배**   | **패배**: 시간 종료 또는 적에게 발각 / **승리**: 제한 시간 내 최대한 많은 배달. |
| **결과 화면**   | 최종 배달 횟수와 '최고 기록' 출력 및 재시작 버튼 제공.                          |
